✅ CE QUE VOUS DEVEZ ABSOLUMENT FAIRE
1. Structure obligatoire :
def control(error, dt, **kwargs):

2. Règles strictes :
  • ✅ Fonction nommée `control` (exactement !)
  • ✅ Premiers paramètres : `error` et `dt` (dans cet ordre)
  • ✅ Retour : nombre (0-100) ou tuple `(sortie, état)`
🔧 Comment écrire votre contrôleur :
Option 1 : Simple (recommandé pour débuter)
def control(error, dt, **kwargs):
    kp = kwargs.get('kp', 2.0)  # Récupère votre réglage
    output = kp * error         # Calcul proportionnel
    return max(0, min(100, output))  # Limite 0-100%
Option 2 : Complet (avec intégrale)
def control(error, dt, integral_state=0, **kwargs):
    kp = kwargs.get('kp', 1.5)
    ki = kwargs.get('ki', 0.05)
    
    integral_state += error * dt
    integral_state = max(-100, min(100, integral_state))
    
    output = (kp * error) + (ki * integral_state)
    return max(0, min(100, output)), integral_state
❌ CE QUI EST INTERDIT (ne marchera pas) :
  • ❌ Mauvais nom : `def mon_controleur(...)`
  • ❌ Paramètres manquants : `def control():`
  • ❌ Mauvais retour : `return "50"` ou `return {}}`
  • ❌ Import/exec : `import os`, `exec()`, `eval()`
Procédure rapide :
  1. Écrivez votre fonction control
  2. Sauvegardez avec le bouton "Sauvegarder"
  3. Activez avec "Activer le Code"
  4. Testez dans le tableau de bord

Note de sécurité : En cas d'erreur, le système bascule automatiquement sur le contrôleur par défaut (sans risque).

💡 Conseils supplémentaires :

  • Testez différentes valeurs de gains (Kp, Ki, Kd)
  • N'oubliez pas de gérer les saturations (0-100%)
  • Le contrôleur personnalisé apparaîtra comme "Personnalisé" dans le tableau de bord
  • Votre code est sauvegardé sur le serveur et localement
  • Utilisez **kwargs pour récupérer vos paramètres de réglage
